About DevVault & How Uploads Work
Upload access is restricted. This section explains the full system — what it is, who can upload, where files are stored, and how to get access.

What is DevVault?

DevVault is a community-maintained library of developer resources — guides, config files, code snippets, tools, and curated news links. It's meant to be like a useful drawer you actually go back to, not a graveyard of bookmarks.

🔐 Who can upload?

  • Only authorised contributors can upload or publish resources.
  • You get access by applying via the form below — the admin reviews it.
  • New contributors are reviewed manually — usually within a few days.
  • Once approved, you get a login and an upload dashboard.

🗄️ Where are files stored?

  • Files are stored in Supabase Storage (cloud bucket).
  • The database stores metadata: title, description, uploader, date, file URL.
  • Files are never stored on the web server itself.
  • Downloads go directly from the bucket to the user.

⚙️ Tech stack

  • Frontend: This HTML file
  • Backend: Supabase (free tier) — auth, database, storage.
  • Auth: Supabase Auth with email magic links
  • Hosting: Netlify, Vercel, or GitHub Pages

📤 Upload flow

  • 1. Log in with your contributor account
  • 2. Go to the Upload Dashboard (hidden from public nav)
  • 3. Fill in: title, description, category, tags, file
  • 4. File uploads to the storage bucket
  • 5. Resource appears in the public listing
